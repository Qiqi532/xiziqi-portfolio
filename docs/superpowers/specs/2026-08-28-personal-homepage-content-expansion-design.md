# 个人主页内容与影像扩展设计

**日期：** 2026-08-28  
**状态：** 用户已批准最终视觉设计，等待书面规格确认后实施

## 1. 目标

在现有个人主页基础上完成第二轮扩展，使网站以彩色生活影像建立亲和力，以项目、论文、奖状和媒体版面支撑可信度，并解决横竖照片混排时的裁切与留白问题。

本轮不改变现有五项导航，也不重构摄影作品集。改动集中在首页、研究学习、个人实践、关于页、公开联系方式和对应静态内容数据。

## 2. 已选设计方向

用户在视觉预览中确认统一采用 A 方案：

1. 首页使用“左右分栏彩色生活照轮播”。
2. 关于页使用“编辑式混合网格”。
3. 研究页使用“项目叙事 + 证据侧栏”。
4. 实践页使用“校园媒体、全运会、社会实践三章叙事”。

整体延续现有明亮、克制的编辑风格，但取消个人生活照片上的黑白和灰度处理。证书、论文页面和报纸版面保持原始色彩。

## 3. 首页

### 3.1 首屏结构

- 左侧保留姓名、身份、主张句、个人简介和研究/摄影入口。
- 右侧以轮播替代证件照，只使用泉州、香港、长城、杭州四张生活照。
- 每张图片在数据中保存独立 `object-position`，不能用同一个裁切焦点处理所有图片。
- 桌面端使用稳定的竖向或近竖向画框；移动端改为上下结构，并降低画框高度，确保正文先于轮播控件被理解。
- 首页任何位置都不出现证件照。

### 3.2 轮播行为

- 默认每 5 秒自动切换，可通过前后按钮和分页指示手动切换。
- 鼠标悬停、键盘焦点进入轮播和页面不可见时暂停。
- 用户开启 `prefers-reduced-motion` 时不自动播放，只保留手动切换。
- 按钮具有明确中文无障碍名称；图片替换不使用会反复打断读屏的强制实时播报。
- 单张图片加载失败时保留画框背景、图序和切换能力，不影响首屏文字与其他图片。

### 3.3 首页摘要

研究、实践和摄影摘要继续承担专题入口，不在首页堆叠全部奖状或全部论文。移除首页原有个人切面照片区，完整生活照片只在首屏轮播和关于页出现，避免重复。

## 4. 关于页与全部个人照片

### 4.1 图片范围

加载 `intro/pic/` 当前全部 14 张照片。证件照可以作为普通照片出现，但不得成为封面、首张主图或跨列大图。照片不强制添加说明，仅提供准确简短的 `alt` 文本；有明确地点的照片可显示地点标签。

### 4.2 混合比例规则

- 每张图片在数据层标记横图、竖图或方图，并可带独立焦点位置。
- 横图优先跨两列；竖图占单列并可跨两行；方图用于填补节奏空位。
- 每组按 4 至 6 张组织，避免连续竖图造成大面积空洞，也避免连续横图形成机械条带。
- 桌面端允许少量编辑式裁切，但不得裁掉人物头部或主要动作。
- 移动端统一单列，图片使用原始宽高比，不执行固定比例硬裁。
- 关于页不新增弹窗浏览功能，照片保持页面内浏览，避免把生活照片墙变成第二套摄影作品集。

## 5. 研究学习页

### 5.1 内容结构

研究页按“项目—证据—成果”组织，而不是把所有信息压成同等权重的卡片：

1. **光纤温盐同步传感项目**：介绍问题背景、SMF–HCF–CF 微球腔结构、光场仿真、理论推导、函数反演、光谱解调控制程序，以及项目负责人角色和优秀结题结果。正文不公开实验中的具体性能指标。
2. **化学奇异星的证认与探讨**：介绍 LAMOST DR13 光谱、物理特征筛选、机器学习分类和后续深度学习方向。对尚在推进的工作使用“进行中”表述，不把阶段指标包装为最终成果。
3. **LHC 顶夸克标记课程项目**：作为较短的“课程与方法实践”模块，说明使用 PyTorch/CNN 区分 top 夸克喷注与 QCD 背景，并与传统物理方法比较；不将其表述为正式科研论文。

### 5.2 论文

- *Enhanced temperature sensing performance of pure silica MZI and FPI sensors using the harmonic Vernier effect*，`Measurement` 271 (2026) 120953，黄新宏为共同第一作者，DOI `10.1016/j.measurement.2026.120953`。

## 8. 数据与组件边界

继续使用 Vite、React、React Router 和 Framer Motion，不增加 CMS、数据库或外部数据接口。

| 单元 | 职责 | 主要依赖 |
|------|------|----------|
| `siteContent` | 保存个人资料、轮播配置、研究、论文、竞赛、工具、实践和个人照片元数据 | `BASE_URL` 静态资源路径 |
| `HeroCarousel` | 轮播状态、计时、暂停、手动切换与降动效处理 | 首页轮播数据 |
| `Home` | 编排首屏与专题摘要 | `HeroCarousel`、内容数据 |
| `Research` | 项目叙事、论文媒体行、奖状图库和工具分组 | 研究内容数据、静态图片 |
| `Practice` | 三章实践叙事与媒体外链 | 实践内容数据、静态图片 |
| `About` | 个人介绍和自适应混合比例照片墙 | 个人照片元数据 |

原始 PPT、PDF 和大图不直接作为运行时依赖。实施阶段只将经选择、渲染和适度压缩的网页资产复制到 `public/images/`，并保留清晰可读版本用于奖状或论文查看。

## 9. 响应式、性能与可访问性

- 新图片提供明确宽高或 CSS `aspect-ratio`，减少加载时布局跳动。
- 首屏只预加载第一张轮播图，其余轮播图和页面下方图片使用懒加载。
- 所有非装饰图片提供中文 `alt`；奖状的替代文字包含奖项名称与年份。
- 外部链接使用 `target="_blank"` 和 `rel="noreferrer"`。
- 交互控件可由键盘访问，聚焦样式沿用全站视觉系统。
- 360 px 宽手机、常见平板和 1440 px 桌面下不得出现横向滚动、文字遮挡或照片空洞。
