# 个人网站优化检查记录

## 已实现

- 首页按简介、教育背景、三类成果、摄影精选、实践和联系组织；首屏突出中山大学物理学背景与 2027 年将赴南京大学深造，学校标签和学科评估直接展示，校史等完整资料保存在原生展开内容内。
- 研究页区分物理研究与独立开发，保留全部项目、论文和奖项；实践页突出角色成果；关于页照片按原比例展示并附图注。
- 摄影默认精选、分类结果数量、分类内灯箱导航、中文按钮和焦点管理；菜单跨桌面断点关闭；图片失败回退与重试；首页轮播去掉可见暂停按钮，保留左右切换、悬停/聚焦暂停及减弱动画偏好。
- 77 张原图生成 452 个多尺寸 WebP/JPEG 文件，原图保留。所有资源由 BASE_URL 生成链接。
- 按需加载内容页、404、页面标题、中文语言、静态分享元数据及站点图标。
- 影石体验范围明确为 X、GO、Ace Pro；去掉“全系列”及未确认的 GO Ultra 具体机型文字。
